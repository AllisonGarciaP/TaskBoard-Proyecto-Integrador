# Semana 13 — API REST con Laravel

Práctica de Integración de Sistemas sobre servicios web REST, JSON y API Resources.

## Contenido

- `ENTREGA_SEMANA13.md`: documento de entrega y resumen de las pruebas.

- Filtrar reservas por estado.
- Comprobar errores 404 y 422.
- Eliminar registros con respuesta 204.
